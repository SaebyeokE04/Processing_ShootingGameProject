# 나만의 필터 스튜디오

Processing 4 Java 모드로 제작한 데스크톱 사진 편집 앱입니다.

## 실행

1. 저장소를 내려받아 압축을 풉니다.
2. Processing 4의 라이브러리 관리에서 **Video Library for Processing 4 2.1 이상**을 설치합니다.
3. `MyFilterStudio/MyFilterStudio.pde`를 열고 Java 모드에서 실행합니다. 폴더 이름과 메인 파일 이름을 변경하지 마세요.

## 주요 기능

- JPG/PNG 불러오기, 사진 목록과 사진별 편집 설정 유지
- 원본·흑백·세피아·필름·픽셀아트·만화풍 필터
- 밝기·대비·채도·필터 강도, 반전·90도 회전·드래그 자르기
- 원본 비교, 초기화, 원본 해상도를 기준으로 PNG/JPG 저장
- 실시간 웹캠 및 촬영, 연결 취소와 시간 초과 안내
- 한 장에 네 가지 필터 또는 선택한 네 장으로 2×2 네 컷 합성
