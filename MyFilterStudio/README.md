# 나만의 필터 스튜디오

Windows · Processing 4 · Java 모드용 기말 과제 프로젝트입니다.
`MyFilterStudio` 폴더 안의 `MyFilterStudio.pde`를 열면 나머지 PDE 탭도 함께 열립니다.
기존 작업을 변경하지 않고 별도 폴더에 작성했습니다.

## 설치와 실행

1. Processing 4를 실행하고 우측 상단 모드를 **Java**로 선택합니다.
2. **스케치(Sketch) → 라이브러리 가져오기(Import Library) → 라이브러리 추가(Add Library)**를 엽니다. 버전에 따라 **도구 → 도구 관리(Manage Tools)**의 Libraries 탭에 표시될 수도 있습니다.
3. `Video`를 검색해 **Processing의 Video 라이브러리 2.1 이상**을 설치합니다. 가능하면 최신 안정 버전을 사용하세요. 이 프로젝트에는 ControlP5 등 별도 UI 라이브러리가 필요 없습니다.
4. 목록에서 설치되지 않으면 [공식 배포 페이지](https://github.com/processing/processing-video/releases)의 `video.zip`을 받습니다. Processing의 **파일 → 환경 설정**에서 스케치북 위치를 확인하고 그 안에 `libraries/video/library/video.jar` 구조가 되도록 압축을 풉니다. 중복된 `video/video` 폴더가 생기지 않게 하고 Processing을 재시작합니다.
5. **파일 → 열기**에서 `MyFilterStudio.pde`를 열고 ▶ 실행합니다.
6. Windows **설정 → 개인정보 및 보안 → 카메라**에서 카메라 액세스와 데스크톱 앱의 카메라 액세스를 켭니다. Teams, Zoom 등 카메라를 점유하는 앱을 닫습니다.

공식 릴리스는 Processing 4에 Video 2.1 이상을 사용하라고 안내합니다. [Video 공식 문서](https://processing.org/reference/libraries/video/)와 [Capture 문서](https://processing.org/reference/libraries/video/Capture)도 참고하세요. 라이브러리가 설치되지 않으면 import 단계에서 실행되지 않으므로 **사진만 편집하더라도 Video 설치는 필요**합니다. 설치 후 웹캠이 없는 것은 정상적으로 처리합니다.

## 사용 순서

### 사진 편집

1. 상단 **사진 불러오기**에서 JPG/JPEG/PNG 한 장을 선택합니다. 버튼을 반복해서 누르면 목록에 계속 추가됩니다.
2. 왼쪽 썸네일을 클릭하여 현재 사진을 바꿉니다. 목록의 ▲/▼ 또는 목록 위에서 마우스 휠로 이동합니다. 각 사진의 설정은 실행 중 유지됩니다.
3. 오른쪽에서 여섯 가지 필터를 선택하고 밝기·대비·채도·강도·픽셀 크기를 조절합니다. 픽셀 크기는 픽셀아트 필터에서만 결과에 영향을 줍니다. **원본** 필터도 밝기·대비·채도 조절을 할 수 있습니다.
4. **좌우 반전**, **90° 회전**으로 방향을 바꿉니다. 반전과 회전은 기존 자르기 영역을 해제합니다.
5. **자르기 영역**을 누르고 비율 버튼으로 자유/1:1/4:3/16:9/3:4를 고릅니다. 전체 사진 위에서 대각선으로 드래그한 후 **자르기 적용**을 누릅니다. 취소하면 이전 자르기가 유지됩니다. 다시 자를 때도 전체 원본 화면에서 새 영역을 정합니다. 지나치게 작은 영역은 적용되지 않습니다.
6. **원본 비교**를 누르면 모든 편집 이전의 원본 전체를 표시하고, 다시 누르면 편집 결과로 돌아옵니다. 비교 중 저장해도 편집 결과가 저장됩니다.
7. **현재 사진 초기화**로 필터·색상·방향·자르기를 모두 기본값으로 돌립니다.
8. **PNG 저장 / JPG 저장**을 눌러 위치를 선택합니다. 저장 형식은 누른 버튼을 따릅니다. 입력 확장자가 다르면 올바른 확장자로 보정합니다. 기존 파일은 덮어쓰기 확인을 거칩니다. PNG는 투명도를 보존하고 JPG는 투명 영역을 흰색에 합성합니다.

### 웹캠

1. **웹캠 켜기**를 누르면 선택된 장치의 첫 프레임을 기다립니다.
2. 오른쪽 필터와 색상 조절·반전·회전이 실시간으로 적용됩니다. 웹캠에서는 자르기를 사용할 수 없습니다.
3. **촬영**을 누르면 현재 원본 프레임과 웹캠 편집 설정을 새 사진으로 보관하고 사진 편집으로 전환합니다. 필터가 이미 입혀진 화면을 다시 필터링하지 않습니다.
4. 장치를 바꾸려면 웹캠을 끄고 **카메라 선택**을 눌러 장치를 순환한 뒤 다시 켭니다. 장치가 제공하는 해상도/프레임률 조합이 각각 목록에 나타날 수 있습니다.
5. 연결 중에는 상단 버튼이 **연결 취소**로 바뀝니다. 장치 검색·연결·읽기는 별도 작업 스레드에서 진행하므로 드라이버 응답 대기 중에도 사진 불러오기를 사용할 수 있습니다. 10초간 프레임이 없으면 작업 단계와 함께 시간 초과를 안내하고 사진 모드로 복귀합니다. 이전 드라이버 호출이 계속 응답하지 않으면 추가 연결 요청은 차단합니다. 이 경우 Processing의 ■ 정지 후 다시 실행하세요. 네이티브 드라이버가 JVM 자체를 멈추거나 충돌시키는 경우까지 복구하지는 못합니다.

웹캠이 연결되지 않으면 Windows **카메라** 앱에서 먼저 영상이 나오는지 확인하고 그 앱을 닫으세요. Zoom/Teams/Discord 등 다른 카메라 사용 앱도 닫고 Windows 카메라 설정에서 **데스크톱 앱의 카메라 액세스**를 확인하세요. Processing 콘솔에는 `[웹캠] 장치 검색/장치 열기/캡처 시작/프레임 읽기` 단계와 예외를 출력합니다.

### 네 컷

- **한 장 × 4필터**: 현재 사진을 원본/흑백/세피아/필름으로 2×2 배치합니다. 현재 사진의 밝기·대비·채도·강도·방향·자르기는 유지되므로 강도 0이면 필터 차이가 보이지 않습니다.
- **선택한 네 장**: 썸네일 왼쪽 작은 칸을 눌러 네 장을 고른 후 실행합니다. 번호 순서대로 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래에 놓습니다. 각 사진의 편집값을 적용합니다. 작은 칸을 다시 누르면 선택이 해제됩니다.
- **여백**: 0/16/32/48/64/80px 순환. **배경색 변경**: 크림/다크/핑크/민트 순환.
- 네 컷 화면에서 PNG/JPG 저장을 누르면 **2048×2048** 합성 이미지가 저장됩니다. 사진은 셀 안에 비율 유지로 맞추며 남는 부분은 배경색으로 채웁니다.
- **사진 편집으로** 또는 다른 썸네일을 눌러 편집으로 돌아옵니다.

## 화면과 성능

- 기본 창은 1100×825이며 1200×900 기준의 화면을 비율에 맞게 표시합니다. 크기 변경 시 모든 패널을 동일 비율로 축소/확대하고 가운데 배치합니다. 작은 창에서도 겹치지 않지만 글씨가 작아지므로 기본 크기 이상을 권장합니다.
- 맑은 고딕 → Noto Sans CJK KR → 나눔고딕 → Java Dialog/SansSerif 순으로 설치 폰트를 찾습니다. 네모 글자가 나오면 Windows의 한국어 보조 글꼴 또는 Noto Sans CJK KR 설치 후 다시 실행하세요.
- 사진 미리보기는 최대 긴 변 1000px, 웹캠 800px입니다. 설정 변경 시에만 사진을 다시 계산합니다. 웹캠은 새 프레임 도착 시 계산합니다.
- 일반 저장은 축소하지 않고 원본에 회전과 자르기를 반영한 크기로 계산합니다. 예: 4000×3000 원본을 90° 회전하면 3000×4000입니다.
- 고해상도 저장/불러오기는 잠시 화면을 멈출 수 있습니다. 많은 고해상도 사진은 RAM을 많이 사용하므로 환경 설정의 최대 메모리를 조절하거나 사진 수/크기를 줄이세요. 특히 만화풍은 경계 연산 때문에 웹캠 속도가 낮아질 수 있습니다.
- 필름 입자는 원본 좌표에 고정됩니다. 축소 미리보기는 원본의 일부 좌표를 샘플링하므로 고해상도 저장과 픽셀 단위로 같은 화면은 아니지만 위치 기반 입자 규칙과 효과값은 동일합니다.

## 제한과 제출 전 확인

- 편집값과 사진 목록은 실행 중 메모리에만 보관합니다. 앱 종료 후 프로젝트 상태 복원/실행 취소/사진 목록 삭제는 제공하지 않습니다. 결과 이미지를 저장하세요.
- JPEG의 EXIF 방향 메타데이터 자동 회전은 제공하지 않습니다. 필요하면 90° 회전 버튼을 사용하세요. 애니메이션 PNG는 정지 이미지로 취급합니다.
- 전체 해상도 처리는 최근접 샘플링을 사용합니다. 미리보기와 저장의 크기 차이 때문에 세부 경계와 입자가 다르게 샘플링될 수 있습니다.
- 실제 Windows 장치에서 웹캠 시작·다른 장치 선택·촬영·종료를 확인하세요. Video/GStreamer 네이티브 환경과 카메라 권한에 따라 다릅니다.
- 파일 선택 취소, 저장 취소/쓰기 불가 경로, 한국어 경로, 창 크기 변경, 네 장 선택 순서도 제출 전에 확인하세요.

검증 결과는 `검증결과.md`, 발표 설명은 `발표요약.md`에 기록합니다.
