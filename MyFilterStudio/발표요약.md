# 발표 요약 — 나만의 필터 스튜디오

## 1. 주제와 흐름

사진 또는 웹캠 → 실시간 필터 미리보기 → 사진 선택/촬영 → 세부 편집 → 일반 이미지 또는 네 컷 저장.
같은 원본에서 여러 결과를 만드는 개인 사진 스튜디오이다. Processing 4 Java 모드와 Video 라이브러리를 사용한다.

## 2. 파일과 클래스

| 파일 | 역할 |
| --- | --- |
| MyFilterStudio.pde | setup/draw, 화면 배치, 마우스 입력, 도구 상태, 사진 전환 |
| Models.pde | Photo(원본·썸네일·Edit), Edit(설정), Button/Slider(UI) |
| ImageEngine.pde | 역좌표 변환, 색상 연산, 여섯 필터, 네 컷 합성 |
| FilesAndCamera.pde | 파일 선택 콜백, PNG/JPG 인코딩, Capture 생명주기/오류 처리 |

사진마다 `Photo.original`과 `Photo.edit`를 저장한다. 필터 함수는 새로운 PImage를 반환하며 원본을 수정하지 않는다. 슬라이더를 여러 번 움직여도 매번 원본부터 계산하므로 효과가 누적되지 않는다.

## 3. 필터 원리

| 필터 | 원리 |
| --- | --- |
| 원본 | 필터 색상 변환을 생략한다. 공통 색상 조절과 방향·자르기는 적용 가능 |
| 흑백 | Y = 0.2126R + 0.7152G + 0.0722B를 R/G/B에 함께 대입 |
| 세피아 | RGB에 3×3 색상 행렬을 곱하여 갈색 톤을 만듦 |
| 필름 | R을 늘리고 B를 줄임 → 위치 해시 입자 추가 → 중심으로부터 거리의 제곱에 따라 주변 밝기 감소 |
| 픽셀아트 | 원본 폭 대비 일정 크기 블록의 중심 색상을 반복 사용하고 RGB를 각각 6단계로 양자화 |
| 만화풍 | 주변 3×3 밝기에 Sobel 연산 → 경계 크기를 어둡게 강조 → RGB를 5단계로 양자화 |

필터 강도는 `원본 × (1−강도) + 필터결과 × 강도`이다. 채도는 밝기와 RGB 사이 보간, 대비는 127.5를 중심으로 곱셈, 밝기는 상수 덧셈으로 조절한다. 각 채널은 최종적으로 0~255 범위로 제한한다.

## 4. 회전·반전·자르기

출력 픽셀 좌표를 정규화한 후 자르기 영역에 대응시킨다. 좌우 반전과 90° 단위 회전을 역으로 적용해 원본 픽셀을 읽는다. 변환 결과를 다시 변환하는 방식이 아니므로 반복 회전에 따른 열화가 없다. 자르기는 회전/반전된 전체 화면 기준으로 저장한다. 방향 변경 시 자르기는 해제하여 좌표 해석을 명확하게 한다.

## 5. 미리보기와 저장

사진은 `dirty`가 true일 때만 축소 결과를 다시 만든다. 웹캠은 새 프레임을 읽을 때 dirty를 켠다. 저장은 원본으로부터 긴 변 제한 없이 재계산한다. 파일 선택 콜백은 선택 결과만 전달하고 실제 앱 상태 변경은 draw 스레드에서 처리한다.

저장은 UI를 캡처하지 않고 결과 PImage만 ImageIO로 인코딩한다. PNG는 알파 유지, JPG는 흰 배경 합성이다. 같은 폴더 임시 파일에 먼저 인코딩하고 완료된 파일을 대상 경로로 이동하여 인코딩 실패로 기존 파일이 손상될 가능성을 줄인다.

## 6. 네 컷과 웹캠

네 컷은 동일 사진에 네 필터를 적용하거나 선택한 네 Photo의 설정을 각각 적용한다. 셀에 비율 유지하여 넣고 2048×2048 RGB 캔버스에 합성한다.

웹캠은 Capture.list → Capture 생성 → start → available/read → 원본 프레임 복사 → 필터 처리 순서이다. 촬영 시 원본 프레임과 Edit 복사본을 함께 보관한다. 장치 종료에는 stop/dispose를 호출한다. 장치 없음과 예외, 프레임 타임아웃을 안내하고 사진 모드로 복귀한다.

카메라 검색부터 읽기와 해제까지는 하나의 별도 작업 스레드에서 처리한다. UI는 volatile로 공개된 독립 프레임 복사본과 상태만 읽는다. 연결 취소 시 active 플래그를 내리며, 늦게 도착한 프레임은 무시한다. UI에서 10초 제한을 감시하므로 장치 초기화 호출이 응답하지 않아도 사진 모드로 돌아올 수 있다. 이전 작업이 멈춰 있으면 새 연결 스레드를 추가하지 않는다.

## 7. 발표 시연 순서

1. 사진을 불러와 필름 필터와 강도를 조절하고 원본 비교.
2. 회전 후 1:1 드래그 자르기, PNG 저장.
3. 두 번째 사진을 불러온 뒤 첫 사진으로 돌아가 설정 유지 확인.
4. 웹캠에서 필터 변경 후 촬영하여 추가 편집.
5. 한 장 × 4필터 합성, 여백/배경 변경, JPG 저장.
6. 사진 네 장을 순서대로 선택하여 별도 합성.

개선 방향: 작업 상태 파일 저장, Undo/Redo, 비동기 고해상도 렌더링, 보간 품질과 GPU 가속.
